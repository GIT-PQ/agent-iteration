# 验收标准模板 v1

> **使用方式**：变更设计阶段（3.2）在 `iterations/{任务编号}/` 下新建 `02-验收标准.md`，按下方骨架填写。
>
> **消费方**：测试准备（3.3）——成功标准转为修复验证项，结构不变量与影响面转为回归项；验证方（干净上下文）只读本文件与工件，**不读变更方案**，避免被实现意图带偏。
>
> **与 eval 的对应**：「对应 eval」列由 3.3 生成 eval 后回填——每条标准都要有可执行载体，每条 eval 都可溯源到标准。
