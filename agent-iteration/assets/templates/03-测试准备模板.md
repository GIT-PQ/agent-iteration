# 测试准备模板 v1

> **使用方式**：测试准备阶段（3.3）在 `iterations/{任务编号}/` 下新建 `03-测试准备.md`，按下方骨架填写。
>
> **职责边界**：本文件只放 eval 之外存不了的两样东西——脱敏对照表和 eval 清单。eval 内容、baseline 明细一律不在此复述。3.3 结束一次写完，之后只读。
>
> **脱敏对照为什么在这里**：eval 与测试输入必须不含真实业务信息；对照表是唯一的还原路径，放任务私有目录以隔离敏感信息。
