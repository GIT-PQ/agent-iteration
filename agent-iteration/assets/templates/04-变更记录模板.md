# 变更记录模板 v1

> **使用方式**：修改实现阶段（3.4）结束时在 `iterations/{任务编号}/` 下新建 `04-变更记录.md`，按下方骨架填写，一次写完。
>
> **职责边界**："改了什么"由 git diff 承载，"为什么改"由 02-变更方案.md 承载，"改得对不对"由 3.5 验证承载——本文件只记偏离和指针。
>
> **自检 ≠ 验证**：自检是修改内循环的退出状态（导航用），不是验证；验证由 3.5 在干净上下文中独立执行。

## 落盘骨架（复制到 iterations/{任务编号}/04-变更记录.md 后填写）

```markdown
---
任务编号：T-001
日期：YYYY-MM-DD
执行者：
依据：02-变更方案.md
---

## 候选版本

- commit：hash（tag 由 3.6 门禁通过后打，此处不记）

## 自检

（修改内循环的退出状态，如实填写实际跑了什么）

- 当前失败 eval：
- 回归范围：跑了 N 条 / 未扩大

## 偏离记录（无偏离写"无"）

（方案不可行 / 越出触及清单 / 临时补救 / 人工裁决——
 每条：发生了什么、怎么处理、依据）
```
